# 資料集使用與限制

更新日期：2026-09-30。下列公開資料支援網路、溯源或製程研究，**均不提供本專案所需的成對核准基線、實際設定快照及變更工單真值**。因此不可把其攻擊標籤直接改稱「設定飄移」標籤。

## Sherlock v3：IEC 104 與電網製程

[論文](https://arxiv.org/pdf/2504.06102)與 [Zenodo v3 紀錄](https://zenodo.org/records/18467070)提供三個電網場景、不同觀測點的 IEC 60870-5-104 封包、IPAL 表示、設備日誌、製程真值，以及攻擊、恢復和正常事件標籤。01-Basic 和 02-Semiurban 有正常訓練資料及測試資料；03-Rural 只有測試資料，可用於場景遷移實驗。v3 修正 01-Basic 和 02-Semiurban 的 IPAL 表示錯誤；重現研究須固定為 v3 並記錄所用檔案與校驗值。

適合驗證：維護事件誤報、IEC 104 網路／製程子模組、事件級檢測與跨電網場景泛化。論文中的 **“Drift Off” 是逐漸偽造電壓量測**，不是設定檔飄移。Sherlock 的設備日誌與製程資料不能替代核准設定快照。原論文將維護視為正常運作，並建議報告攻擊事件檢出、誤報及偵測時間，而非只看逐時間點 F1。

## GeCo：製程模型與可重現程式

[GeCo 論文](https://www.usenix.org/system/files/usenixsecurity25-wolsing.pdf)研究從規則間隔的正常製程時序學習可理解的狀態模型；線上偵測使用當下製程狀態。其[研究 artifact](https://zenodo.org/records/15120036)包含程式、參數、模型與結果，另有[持續維護的 IPAL 實作](https://github.com/ipal-ids/ipal_ids_framework/tree/master/ids/geco)。GeCo 是方法與程式 artifact，不是一套設定快照資料集；artifact 的程式與結果也不能視為已取得各個原始評估資料集的使用權。

適合驗證：在自建測試床或具有相容時序的公開資料上，製程模型是否能為設定事件提供後果證據；比較有無製程模態的告警解釋與排序。不能用 GeCo 的製程偏差直接宣稱設備設定被修改。

## ProvICS：Modbus 與跨層資料

[2026 預印本](https://arxiv.org/html/2607.05989v1)及[資料卡](https://huggingface.co/datasets/trucyberlab/multimodal-ICS-provenance)描述單 PLC、數位分身硬體迴路測試床。資料同步包含監控主機及 PLC 溯源、解碼的 Modbus/TCP 記錄、封包和製程時序；資料卡列出 48 小時正常階段、22 小時攻擊階段、四個戰役與 32 個標註攻擊事件。原始大型 JSON／JSONL 資料需從檔案頁取得，網頁表格預覽不是完整資料。資料卡標示 **CC BY-NC 4.0**，使用前應重新檢查授權條件和下載檔案。

適合驗證：時間對齊、來源追溯、Modbus 命令語意與跨模態融合的子模組。限制包括單 PLC、數位分身製程、戰役數少，以及沒有完整的核准設定快照與維護工單真值。資料中部分事件涉及程式或流程改動，仍不能假定全部事件都對應本專案欄位級設定變更。留戰役評估時，須避免將同一戰役的相鄰時窗分到訓練和測試兩側。

## 必須自建的設定變更資料

在經授權、隔離的虛擬 PLC／閘道環境收集：

1. **核准基線**：設備與控制點身份、設定內容、版本、雜湊、有效期間。
2. **實際快照**：由獨立且唯讀的來源採集；記錄來源、採集時間、成功／失敗、資料新鮮度及欄位可見度。
3. **變更脈絡**：工單、操作者角色、核准範圍、維護窗口、回滾紀錄與設備模式。
4. **可選後果資料**：被動網路紀錄、主機／PLC 日誌、製程量測與時鐘同步品質。
5. **事件真值**：變更起迄、受影響欄位、授權狀態、是否觀察到後果及標註者／標註依據。

初始實驗至少覆蓋核准與未核准變更各自有、無製程影響的四組，加上快照缺失、時鐘偏差及回滾。採集流程不得對生產 OT 設備主動掃描或下發控制命令。分享資料時移除憑證、可路由地址和其他敏感資訊；原始大型資料與受授權限制的第三方資料不直接提交到本 repo。

## 資料版本與可重現性

每次實驗記錄來源 URL、下載日期、版本／提交雜湊、授權、檔案雜湊、前處理腳本版本、時間基準、欄位映射和資料切分清單。先制定標註準則並凍結測試集，再調整門檻。公開資料的結果標為「網路／製程／溯源子模組」；只有具備成對設定與核准真值的自建資料，才用來報告設定飄移檢出率。
